# Benjamin MacMillan — Engineering Portfolio

Personal engineering portfolio built as a static website for GitHub Pages.

## Before publishing
1. Put a PDF copy of the resume in the root folder and name it `resume.pdf`.
2. Replace the project image placeholders as photos become available.
3. Upload all files/folders to the `benmacmillan-eng.github.io` repository.
4. Open **Settings → Pages** in GitHub and deploy from the `main` branch.

The site uses plain HTML and CSS, so there is no build process or framework to maintain.
